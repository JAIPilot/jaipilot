# Third-party notices

The native JAIPilot executables contain the Go standard library and runtime (BSD-3-Clause), with its license in `licenses/go.txt`. JAIPilot is MIT licensed; see `LICENSE`.

The JavaScript MCP and ACP SDKs are used only for development compatibility tests. They are not included in the native executable or downloaded by the standalone installers.

The npm launcher uses Node.js supplied by the user. Direct and Homebrew installations require no JavaScript runtime. Git, a JDK, and the repository’s build tools remain necessary for Java work.
