# JAIPilot brand

## Positioning

**JAIPilot is proof-driven Java engineering for coding agents.**

Primary promise: **Generate tests. Clean Java. Prove every change.**

Use concrete language about isolation, real builds, execution evidence, fresh coverage, drift
protection, and transactional apply. Avoid unsupported “best,” “magic,” autonomous-developer, or
universal SonarQube-replacement claims.

## Voice

- Precise before impressive.
- Confident because evidence is visible.
- Technical without internal implementation clutter.
- Local-first and privacy-aware without fear-based language.
- Direct about boundaries and complementary tools.

## Visual system

| Role | Color | Hex |
| --- | --- | --- |
| Ink | Deep navy | `#081426` |
| Primary | Electric blue | `#60A5FA` |
| Transition | Cyan | `#22D3EE` |
| Proof | Green | `#34D399` |
| Foreground | Cloud white | `#F8FAFC` |
| Secondary text | Steel | `#B8C7DD` |

The mark combines a `J`-shaped path with a verification check. Keep clear space around it equal to
at least one quarter of the mark width. Do not recolor individual strokes, stretch the mark, add
drop shadows outside the supplied asset, or place it on low-contrast backgrounds.
